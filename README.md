# trt.Schulmanager

Ein FastAPI-Backend für Lehrer, inklusive Telegram-Bot-Integration.

## Features
- Klassenverwaltung
- Telegram-Bot-Integration (/status, /heute, /codes)
- Datei-Ablage

## Sicherheit
- TruffleHog-Scan ist in den GitHub Actions integriert.

## Deployment
- Docker-Compose wird unterstützt.
